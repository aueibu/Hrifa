Mixing matrix

[[1,1],[1,2]] (the textbook Arnold cat map) is just the default here, not a rule — any integer matrix works. Bijective on this grid iff gcd(det, N) = 1, same principle as the AFT's own gcd(a,m)=1 rule.

Tree growth (radial engine)

Grows a branching tree from the arrival field: nearest-neighbor circles (O, P) at an origin point set a seed radius Q, then each child hops outward via a directed ray search. Ctrl+click a point on the grid (right canvas) to set the origin.
