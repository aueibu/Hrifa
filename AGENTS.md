# Agent instructions

All active work in this repo happens in `shell/` (React + Vite + Mantine,
TypeScript, Yarn Berry via `corepack yarn` from inside `shell/`).

Read `CLAUDE.md` at the repo root first: it has the repo layout and the read
order for `shell/` (`shell/CLAUDE.md`, `shell/ARCHITECTURE.md`,
`shell/DECISIONS.md`, `shell/UI-RULES.md`, `shell/arcs/`). Those rules apply to
every agent, not only Claude.

`legacy/` is archived: the old vanilla-JS portal and applets. Don't read, edit
or borrow conventions from it unless the user asks for something in it.
