Quasi-solarized theme

This is the palette and type stack improvised while prototyping Point Construction, before that applet was migrated onto the shared design-tokens system. It reads like a cool, desaturated riff on Solarized — a dark ink-blue/near-black ground with a warm amber accent and a spread of muted line/arc/circle/point hues. Kept here standalone so it can be looked at again later: as a candidate seasonal theme, a one-off applet identity, or just discarded. It is not wired into design-tokens and changes here have no effect on any applet.

Hue-variant demo (~44° spread)

Each role's base hue gets shifted across however many instances exist on screen, so multiple objects of the same role stay tellable apart without leaving the family. This is the one piece of the original prototype worth keeping regardless of which palette wins — see variantColor() in point-construction/app.js.
