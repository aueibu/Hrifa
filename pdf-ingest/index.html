PDF Ingest

This tool processes local PDFs into LLM-readable Markdown. It runs on your computer rather than GitHub Pages so files stay local.

cd pdf-ingest
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python app.py

Then open http://localhost:5000. Optional OCR requires Tesseract to be installed separately.
