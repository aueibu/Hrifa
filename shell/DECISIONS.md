# DECISIONS

Cross-project decisions: choices that touch shared code or a shared contract (pitch and tuning representation, time, PianoRoll behaviour, theme, the desk and edit contract, persistence boundaries, the multi-arc workflow). Arc-local choices stay in that arc's `PROGRESS.md`. The map these decisions apply to is `ARCHITECTURE.md`.

## Append protocol

- Append-only. Add new rows at the BOTTOM; never reorder or delete rows. To change a decision, add a new row and set the old row's `status` to `superseded by <id>` (editing the status cell is the only allowed edit of an existing row).
- No lock is needed to add rows (rows are never deleted; `arcs/LOCKS.md` lists this file among the shared docs that need no lock). Any session may `git add` this file; another session's rows riding along in someone's commit are accepted. Re-read the bottom of the file just before appending so concurrent arcs do not collide.
- Ids are arc-prefixed and numbered per prefix in order. Every prefix must be unique and is registered in the workstream's FIRST row here (that row says "registers prefix X") and in the registry below; check the registry before choosing one (T is the intended prefix for the tunings workstream but is not registered until its first row exists). Take the next unused number for your prefix.
- Columns: `id`, `date` (YYYY-MM-DD), `arc` (workstream folder, with the arc topic when useful), `decision`, `why` (one line), `affects` (workstreams or pages that read it), `status` (`active`, `superseded by <id>`, `reverted`), `source` (the document that records it: seed rows point at the archive text; later rows name the PR, ARC.md or PROGRESS entry). Where a source is a bold paragraph label rather than a heading, the source cell says so.
- A reviewer checks, for every change that touches a shared contract, that a row exists here (`CLAUDE.md`, "Several arcs at once", rules 6 and 7).
- Seed rows (W-1 to W-12, S-1 to S-8) record decisions already made and written down elsewhere. Their dates are the dates stated in the source; where the source gives none the date is written `2026-11-12 (assumed)` (the date this log was created). Only W-1 and W-2 are assumed.
