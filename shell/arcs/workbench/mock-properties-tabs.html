Blender's header, and our parallel

  • Blender (manual, "Data-Block Menu"): the first row of a tab is the data-block menu: a type icon with a drop-down arrow (opens the list with a search field; tooltip "Browse X to be linked"), the name (editable), the user count (click = single-user copy), Fake User, New, and Unlink (x). Above it sits a plain path line.
  • Ours: the Object row has no picker (the Outliner selects). The Data tab is the real parallel of Blender's "Browse Mesh to be linked": its row links the object's data (Notes, Pitch Set, and so on) and carries the user count, New (duplicate) and Unlink. Unlink is today's "None" button (the object becomes an Empty). Today's Data row, Users row, Make Single User and None button all fold into this one row.
