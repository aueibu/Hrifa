Placement Catalog Checkpoint

Built with the new library code. The essential intervals are placed by their centers in every ordering, and every window starts on C2 (the window is a width only). Equal centers (the default): the centers are equally spaced, as far apart as the window allows, so every chord reaches both the bottom and the top of its window. Shared center range (the second rule): the centers are equally spaced across one range set by the largest interval. Each interval's bottom note is rounded once to the nearest step; an exact half step rounds toward the middle of the window. With a range of window sizes, each size gives one chord per ordering, and all of them are listed together, the same chord once. Default ranking: smooth (low roughness) and harmonic (high pitch-space harmonicity), weighted equally against the other chords in view. Chords stand as columns on one pitch axis, best first from the left. Click a chord for its details and to hear it.
